# FormCoach

FormCoach là hệ thống thị giác máy tính phát hiện và phân tích lỗi tư thế khi tập gym (Back Squat, Overhead Press) theo thời gian thực qua webcam. Dự án tập trung so sánh hai phương pháp:
- **Phương pháp A (Method A):** Luật hình học suy ra từ góc khớp và tương quan giải phẫu.
- **Phương pháp B (Method B):** Mô hình chuỗi keypoint học sâu (1D-CNN, LSTM, Transformer).

Dữ liệu huấn luyện và kiểm thử sử dụng bộ dữ liệu công khai **Fitness-AQA**.
